F1 OUTLOOK MONTHLY MAILER v1.0.0

INSTALLAZIONE
1. Estrai lo ZIP.
2. Clic destro Install-F1-Mailer.ps1.
3. Esegui con PowerShell.
4. Esegui Test-Outlook.ps1.
5. Esegui Test-Email.ps1 per una sola prova.

REQUISITI
Windows 10/11 + Outlook Classic configurato con F1IMMOBILIARESUSA@OUTLOOK.IT.

CONTATTI
Cartella Outlook: F1 CAMPAGNA EMAIL
Categoria necessaria: F1-CONSENSO
Categoria di blocco: F1-DISCRITTO

CONFIGURAZIONE
%LOCALAPPDATA%\F1OutlookMonthlyMailer\settings.json

LOG
%LOCALAPPDATA%\F1OutlookMonthlyMailer\logs

REPORT
%LOCALAPPDATA%\F1OutlookMonthlyMailer\reports

PAUSA / RIPRENDI / TEST / ESEGUI ORA
Apri F1-Control-Panel.ps1.

Il programma non usa Supabase, Graph, Azure, SMTP, Python o Power Automate.
